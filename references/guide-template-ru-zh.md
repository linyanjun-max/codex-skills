# 翻译工作指南模板（俄译中 · 自动控制理论）

> 用法：复制到 `<work>/tr/_GUIDE.md`，按本次任务增补术语，然后在每个子代理提示里
> 要求它**首先**阅读该文件。更换源语言时替换术语表并保留其余约定。

## 0. 总原则

1. **图页图像是唯一权威来源。** `pages/p-NNN.png` 是原 PDF 的逐页渲染图。
   `ptext/pNNN.txt`（pdftotext 提取）**丢失了全部希腊字母和数学符号**——原 PDF 使用
   自定义 Symbol 字体，例如 `ω₀ − ω = ±Δω` 会被提取成 `0   .`。因此纯文本**只能**
   当作识读俄文单词的辅助，**绝不能**用来还原公式、变量或上下标。
2. **不得省略、不得概括。** 原文的每一句话、每一个公式、每一条列项都要翻译。
3. **公式保持原书符号体系**（包括西里尔下标，如 `W_{\text{ДПТ}}`、`T_Д`、`K_{Д1}`）。
   正文中出现的俄文缩写在**文字里**译成中文，在**公式里**保持原样。
4. **不要"修正"原书。** 原书的笔误（系数不一致、`s→∞` 应为 `s→0`、重复项）
   必须照译并在交付说明中报告，否则会丢失可追溯性。
5. 语言：简体中文，工科教材语体，准确、书面、简洁。

## 1. 输出格式（逐行前缀式，严格遵守）

| 标记 | 含义 |
|---|---|
| `@@PAGE n` | 页码标记，**每页开头必须写**，n 为 PDF 页号 |
| `#H1 ` `#H2 ` `#H3 ` `#H4 ` | 各级标题 |
| `#P ` | 正文段落（一段一行，可含行内 `$...$`） |
| `#EQN <编号> <LaTeX>` | **带编号**的行间公式，编号不带括号 |
| `#EQ <LaTeX>` | 不带编号的行间公式 |
| `#FIG <图片文件名> \| <图题>` | 插图，插在原文出现位置 |
| `#BUL ` | 列项（一项一行） |
| `#CAP ` | 图/表下方的说明性文字（按普通段落排版，不首行缩进） |

要点：

* 原文 `(1.1)` 写成 `#EQN 1.1 ...`（程序会自动加括号并右对齐）。
* 公式后的"где …"（式中……）单独写成 `#P` 或 `#CAP`。
* 多字母下标**必须**加大括号：`W_{\text{ДПТ}}(s)`；单字母可写 `T_Д`。
* 图题要译出；图内俄文标注无法重绘，在图题后用括号附中文对照：
  `#FIG fig_p008_00.png | 图 1.1 功能结构图（ЗУ—给定装置；ССУ—比较求和装置；УУ—控制装置；ОУ—控制对象；ОС—反馈）`
* 表格：每行一条 `#P`，单元格用 ` | ` 分隔；**逐格转写，不得合并重复值**。
* 页眉页码（单独一行 `11`）不要翻译也不要输出。整页只有页码时只输出 `@@PAGE`。
* 跨页断句照实处理，并在报告中说明，便于相邻分块衔接。

## 2. LaTeX 书写约定

* 分式 `\frac{分子}{分母}`；根式 `\sqrt{...}`、`\sqrt[n]{...}`
* 上下标 `x^2`、`x_i`、`x_i^2`
* 希腊字母 `\alpha \beta \gamma \delta \varepsilon \omega \Omega \Delta \varphi \tau \sigma \lambda \mu \nu \xi \rho \theta \eta \zeta \psi \chi`
* 运算符 `\cdot \times \pm \le \ge \ne \approx \to \infty \partial`
* 积分/求和带限 `\int_{0}^{\infty} f(t)dt`、`\sum_{i=1}^{n} a_i`
* 括号 `\left( ... \right)`；函数 `\sin \cos \tan \ln \lg \log \exp \lim \min \max`
* 导数点号 `\dot{x}`、`\ddot{x}`；上划线 `\overline{x}`
* 矩阵 `\begin{pmatrix} a & b \\ c & d \end{pmatrix}`；分段 `\begin{cases} ... \end{cases}`
* **直立文本**（多字母缩写、单位）一律用 `\text{...}`，例如 `\text{ДПТ}`、`\text{с}`；
  **不要用 `\mathrm`**。
* 不要使用 `\tag`、`\label`、`\begin{equation}`、宏定义或其他排版宏。
